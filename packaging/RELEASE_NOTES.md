把 Microsoft [MarkItDown](https://github.com/microsoft/markitdown) 打包成 Windows 執行檔和 Claude skill，可以把 PDF、Word、PowerPoint、Excel、HTML、CSV、JSON、XML、EPUB、ZIP、Outlook .msg、Jupyter Notebook 和網頁（包含 YouTube、Wikipedia）轉成 Markdown。

## 這個版本的更新（1.7.0）

讓最省 token 的做法變成預設，不需要先學會怎麼用：

- **只轉最新一版**：預測瀑布表這類檔案（每個料號在每週的預測版本都有一列），程式會自動找出「版本欄」，在卡片上提供「→ 只轉最新一版 · 約 6 萬 token」、「→ 只轉最新 2 版 · 約 12 萬 token」的連結。按一下就會另外產生一個小檔（檔名後面加「_最新1版」），可以直接拖進 Claude。以 Accton FCST Waterfall 為例：全部約 95 萬 token，最新一版約 6 萬 token。PO 日期、出貨日期這類每天筆數不一樣的日期欄，不會被當成版本欄。命令列用 `--xlsx-latest N`。
- **大檔的卡片會告訴你怎麼傳**：卡片上寫「先拖這張就好，Claude 會說還要哪個檔」；全部超過 15 萬 token 時，會用黃字提醒「太大，別整包上傳」。
- **更早拆成索引加資料檔**：整份超過約 3 萬 token 就會拆開（之前是 15 萬），讓預設拖進 Claude 的永遠是小小的索引。用關鍵字或版本篩選出來的檔案，在 15 萬 token 以內仍然是單一檔案，方便一次交給 Claude。
- **Claude 專案指示**：面板的「更多 › 複製 Claude 專案指示」會複製一段固定指示。貼到 Claude 專案的「指示」欄位之後，Claude 在這個專案裡都會先看索引，需要明細時才開口要檔案，也會提醒你用篩選。
- 索引會標出版本欄和每版有幾列，並提醒 Claude 跨版本相加沒有意義。
- 面板底部改成一整列的設定說明，加上「更多」選單（轉換選項、複製專案指示），文字不會再被截斷。

### 1.6.1

- 修正：表頭如果是跨好幾欄的合併儲存格（例如「MPN」合併了 A1:E2），之前每一欄都會被叫做「MPN」，連實際上是 Site、Brand 的欄也是。現在只有第一欄會用這個名稱，其他欄維持空白，跟 Excel 裡一樣；這些欄的內容可以從索引的統計看出來。跨兩列的表頭（例如 B1:B2）照舊會當成那一欄的名稱。

### 1.6.0

- **快速轉換面板更精緻，加上動畫**（依照 Emil Kowalski 的設計工程原則）：
  - 檔案拖到面板上方時，外框和底色會在 0.15 秒內漸變成藍色，文字在變換的瞬間淡出再淡入，箭頭也會往下移一點；拖走時復原得比較快（0.1 秒）。
  - 第一次有結果時，拖放區會花 0.26 秒收成一行，結果清單從下方展開；按「清除」時再展開回來。展開或收合的途中，下方的選項列不會被擠出視窗。
  - 新的卡片會一邊淡入一邊往上浮 8 像素，同時撐開自己的位置，下面的卡片會滑下去，不會突然跳動。同時出現好幾張卡片時，每張間隔 0.05 秒依序出現。
  - 按住卡片時，卡片會縮到 97% 並稍微變暗，放開就彈回來，讓人知道拖曳已經開始。
  - 進度條會平滑前進。
  - 卡片上的 token 數改用主要文字顏色，「✓ 已逐格核對」用綠色標示；滑鼠移到卡片上時會出現淡淡的陰影。
  - 用鍵盤操作的動作（例如 `Ctrl+Shift+C` 複製、開啟面板）不會有動畫。滑鼠移到卡片上時是立即變色，不做漸變。
  - Windows 關閉「動畫效果」（設定 › 協助工具 › 視覺效果）時，畫面上的東西不會移動或改變大小，只保留較短的顏色漸變。

### 1.5.0

- **快速轉換面板**：一個浮在其他視窗上方的小面板，讓 Excel 到 Claude 的流程變成「拖進來、拖出去」：
  - 把檔案拖進面板就會開始轉換，轉換中也可以繼續拖檔案進來。
  - 每個結果會變成一張檔案卡片，顯示大約需要多少 token，Excel 精簡版還會標示「已逐格核對」。把卡片直接拖進 Claude Desktop 的對話框就能附加檔案。大型 Excel 的卡片是索引檔，卡片上會寫出同資料夾還有幾個資料檔、共約多少 token。
  - 不方便拖曳時：在卡片上按兩下可以開啟檔案；按右鍵可以複製內容、複製路徑或開啟檔案位置；按「選擇檔案…」可以挑選檔案。
  - 開啟方式：主視窗的「檢視 › 快速轉換面板」（`Ctrl+Shift+P`）、主視窗空白時的連結，或 `markitdown.exe --panel`。
  - 面板沿用主視窗的選項；按「選項…」會打開主視窗。「浮在其他視窗上方」可以關閉。

### 1.4.0

- **Excel 預設改為「給 Claude 的精簡版」**，目標是省 token、資料仍然 100% 正確：
  - **`00_索引與邏輯.md`**：每張工作表的欄位、類型、非空格數，以及由程式精確算好的最小值、最大值和合計（有「列分類」欄，例如 Demand/ETD/Balance 時，合計會依分類分開算）。另外列出每欄的公式寫法、工作表之間的資料流向、篩選、隱藏、驗證和樞紐分析表，以及每個資料檔大約要多少 token。Claude 先讀這個小檔，就知道要看哪些資料。
  - **資料**：Tab 分隔、完整精度、沒有格式符號。第一欄是 Excel 列號（隱藏列加 `h`），日期寫成完整的 `YYYY-MM-DD`；如果格式只顯示月份或藏住了時間，也會寫出完整的值。註解附在資料後面。
  - 小檔案（約 15 萬 token 以內）只會產生一個 `.md`。大檔案會產生資料夾 `<檔名>_md\`，裡面有索引和每張工作表的資料檔（太大的會分成幾個部分）。
  - 寫出檔案之前，程式會把資料讀回來，跟活頁簿逐格比對；只要有一格不同就不會產生結果。
  - **只保留含關鍵字的列**：例如只要某幾個料號。命令列用 `--xlsx-rows-containing 料號`，圖形介面在「選項 › Excel：只保留含關鍵字的列…」。表頭列會一起保留，索引裡的統計仍是整張工作表的結果。
  - 實測（一份 8 張工作表、145 萬個非空儲存格的週報）：索引約 2.2 萬 token；全部資料約 540 萬 token，比 1.3 版的完整表格（約 665 萬）少約 18%；用一個料號篩選後，整份只剩約 7.8 萬 token。每一格都和 openpyxl 讀到的值比對過，0 個不同。
  - 原本的完整表格版還在：`--xlsx-format readable`，或在圖形介面取消勾選「選項 › Excel：給 Claude 的精簡版」。「在每個儲存格的值下方附上公式」會自動改用完整表格版。

### 1.3.0

- **Excel 公式**：每張工作表最後會列出所有公式的寫法和使用範圍。同一條公式往下或往右複製只算一種寫法，例如 61 萬個公式整理成 195 種。開頭新增「工作表之間的資料流向」，列出每張工作表的公式和樞紐分析表讀取了哪些工作表。選項 `--xlsx-formulas cells`（圖形介面：「選項 › Excel：在每個儲存格的值下方附上公式」）會在每個值下方附上該格的公式。
- **用 Excel 重新計算**：`--xlsx-recalc`（圖形介面：「選項 › Excel：轉換前先用 Excel 重新計算」）會呼叫你電腦上的 Microsoft Excel，在檔案副本中依序重新計算、重新整理所有樞紐分析表、再算一次，然後才轉換，原始檔不會被修改。需要 Windows 與 Excel 2021 或 Microsoft 365（檔案用到 XLOOKUP）；如果重新計算後出現新的 #NAME? 錯誤，結果開頭會警告。

## 下載哪一個？

| 檔案 | 用途 |
|---|---|
| `markitdown.exe` | **Windows 單一執行檔**，不需安裝 Python。雙擊開啟圖形介面，或在命令列使用。 |
| `markitdown-skill-windows.zip` | Claude skill，內附 `markitdown.exe`（Windows 上的 Claude Code 用這個）。 |
| `markitdown-skill.zip` | Claude skill，僅含腳本（macOS / Linux，或上傳到 Claude App；需要 `pip install "markitdown[all]"`）。 |
| `SHA256SUMS.txt` | 檔案雜湊值，可用來驗證下載內容。 |

## markitdown.exe 用法

- **雙擊**：開啟圖形介面。把檔案或資料夾拖進視窗，按「轉換」。左邊清單會顯示每個項目的狀態，右邊可以預覽、複製 Markdown。外觀會跟著 Windows 的淺色／深色設定切換。
- **拖曳**：把檔案或資料夾拖到 `markitdown.exe` 圖示上，會在原位置產生 `.md`。
- **命令列**：
  ```
  markitdown.exe report.pdf                 # 輸出到螢幕
  markitdown.exe report.pdf -o report.md    # 存成檔案
  markitdown.exe C:\docs -r --out-dir C:\docs_md
  markitdown.exe --help
  ```

> 這個執行檔沒有數位簽章。第一次執行時，Windows SmartScreen 可能會跳出「Windows 已保護您的電腦」，請按「其他資訊」再按「仍要執行」。每次啟動需要幾秒鐘解壓縮。
